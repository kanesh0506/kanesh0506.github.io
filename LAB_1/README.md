# Discover Selangor Tourism Web App

A clean, responsive, single-page tourism guide web application for top attractions in Selangor, Malaysia.

## Features
- **Curated Selangor Destinations:** Batu Caves, Sunway Lagoon, Sky Mirror, Sekinchan Paddy Fields, Firefly Sanctuaries, and more.
- **Dynamic Search & Filtering:** Filter by categories (Culture, Theme Parks, Nature, Eco-Adventure, Heritage) or search by keyword.
- **Interactive Saved Itinerary Builder:** Bookmark favorite spots, calculate saved locations, and copy itinerary summaries.
- **Detailed Modals:** Instant travel tips, opening hours, pricing, and best times to visit.
- **GitHub Pages Ready:** Simple single-file deployment setup.

## How to Deploy to GitHub Pages

1. **Create Repository:** Create a new repository named `selangor-tourism` (or `username.github.io`).
2. **Push Files:** Upload `index.html` and `README.md` to your main branch.
3. **Enable Pages:** Go to **Settings** -> **Pages** -> Select `main` branch `/ (root)` folder -> **Save**.
