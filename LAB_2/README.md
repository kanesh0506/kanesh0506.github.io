# Malaysia Population Analytics Dashboard Package

## Package Contents
1. `index.html` - Interactive Bright Theme Dashboard (Open in any modern web browser)
2. `population_malaysia.csv` - The complete dataset (1970 - 2026)
3. `analysis_summary.md` - Demographic insights and analytical breakdown summary

## Instructions
- Double click `index.html` to open and interact with the population dashboard directly in your browser.
- Ensure `population_malaysia.csv` remains in the same folder if exporting data.
